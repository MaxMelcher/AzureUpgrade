# Recommendation quality matrix

`recommendations-uksouth-linux-family.csv` is generated by `npm run qa:recommendations` from the UK South catalog.

The matrix selects one deterministic, unconstrained Linux-priced representative VM per Azure family.
Each row is one representative x CPU-policy combination and includes the selected recommendation,
retirement status/EOL date, GBP prices, monthly savings, confidence, and explanation. The UTF-8 BOM
and quoted fields make the file Excel-friendly.

When multiple CPU policies produce the same outcome, they are collapsed into one row. A family only
has multiple rows when its recommendation genuinely differs by CPU policy.

The file starts with Excel's `sep=,` directive and a UTF-8 BOM.
